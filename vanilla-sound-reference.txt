ZWEIHANDER SOUNDPACK - VANILLA SOUND REFERENCE (Factorio base mod, 2.0/2.1)
=============================================================================
1) BOT SOUNDS  (data.raw["construction-robot"|"logistic-robot"|"combat-robot"|"roboport"])
-----------------------------------------------------------------------------
construction-robot ("construction-robot"):
  repairing_sound   -> __base__/sound/robot-repair-1.ogg .. robot-repair-6.ogg
  working_sound     -> __base__/sound/construction-robot-1.ogg .. construction-robot-2.ogg (flight loop)
  charging_sound    -> __base__/sound/robot-charging-1.ogg .. robot-charging-7.ogg

logistic-robot ("logistic-robot"):
  working_sound     -> __base__/sound/construction-robot-11.ogg, construction-robot-12.ogg (shared "flying_robot" set)
  charging_sound    -> __base__/sound/robot-charging-1.ogg .. robot-charging-7.ogg (same set as above)

combat-robot ("distractor" / "defender" / "destroyer"):
  distractor.working_sound.sound -> __base__/sound/fight/distractor-robot-loop.ogg
  defender / destroyer use the same robot_animations/working_sound pattern (see entities.lua ~line 550-610)

roboport ("roboport"):
  open_sound        -> __base__/sound/open-close/roboport-open.ogg
  close_sound       -> __base__/sound/open-close/roboport-close.ogg
  working_sound     -> __base__/sound/roboport-working.ogg

utility-sounds (data.raw["utility-sounds"]["default"]) relevant to bots:
  deconstruct_robot -> __core__/sound/deconstruct-robot.ogg   (deconstruction planner "eating" sound)

-----------------------------------------------------------------------------
3) PLAYER / CHARACTER SOUNDS  (data.raw["character"]["character"] and utility-sounds)
-----------------------------------------------------------------------------
character ("character") entity itself only defines one direct sound field:
  heartbeat -> __base__/sound/heartbeat.ogg   (plays at low health)

Everything else player-related lives on utility-sounds (data.raw["utility-sounds"]["default"])
  axe_mining_ore        -> __core__/sound/... (manual mining swing on ore)
  axe_mining_stone      -> __core__/sound/... (manual mining swing on rock/stone)
  mining_wood           -> __core__/sound/... (manual mining swing on trees)
  axe_fighting           -> __core__/sound/... (unarmed/melee punch)
  default_manual_repair  -> __core__/sound/... (repair tool swing, no filename override needed if using default)
  picked_up_item         -> __core__/sound/spawn-item.ogg family (item pickup ding)
  drop_item               -> __core__/sound/... (dropping item on ground)
  inventory_click         -> __core__/sound/... (inventory slot click)
  inventory_move           -> __core__/sound/... (dragging items in inventory)
  clear_cursor             -> __core__/sound/clear-cursor.ogg
  armor_insert / armor_remove -> __core__/sound/armor-insert.ogg / armor-remove.ogg
  switch_gun                -> __core__/sound/switch-gun.ogg
  default_landing_steps     -> __core__/sound/walking/default-land-step.ogg (character footsteps on ramps/platforms)
  build_animated_small/medium/large/huge -> __core__/sound/build-*.ogg (placing buildings by hand)
  deconstruct_small/medium/large/huge -> __core__/sound/deconstruct-*.ogg (deconstruction planner on player-built entities)

NOTE: normal walking footstep sounds (grass/concrete/stone etc.) are NOT on the
character entity - they're defined per-tile in data.raw["tile"][*].walking_sound,
one set per surface material. Ask if you want that full tile-by-tile list too -
it's a much longer table (~30+ tile types x several variations each).
