ZWEIHANDER SOUNDPACK - VANILLA SOUND REFERENCE (Factorio base mod, 2.0/2.1)
=============================================================================
1) BOT SOUNDS  (data.raw["construction-robot"|"logistic-robot"|"combat-robot"|"roboport"])
-----------------------------------------------------------------------------
construction-robot ("construction-robot"):
  repairing_sound   -> __base__/sound/robot-repair-1.ogg .. robot-repair-6.ogg
  working_sound     -> __base__/sound/construction-robot-1.ogg .. construction-robot-2.ogg (flight loop)
  charging_sound    -> __base__/sound/robot-charging-1.ogg .. robot-charging-7.ogg

logistic-robot ("logistic-robot"):
  working_sound     -> __base__/sound/construction-robot-11.ogg, construction-robot-12.ogg (shared "flying_robot" set)
  charging_sound    -> __base__/sound/robot-charging-1.ogg .. robot-charging-7.ogg (same set as above)

combat-robot ("distractor" / "defender" / "destroyer"):
  distractor.working_sound.sound -> __base__/sound/fight/distractor-robot-loop.ogg
  defender / destroyer use the same robot_animations/working_sound pattern (see entities.lua ~line 550-610)

roboport ("roboport"):
  open_sound        -> __base__/sound/open-close/roboport-open.ogg
  close_sound       -> __base__/sound/open-close/roboport-close.ogg
  working_sound     -> __base__/sound/roboport-working.ogg

utility-sounds (data.raw["utility-sounds"]["default"]) relevant to bots:
  deconstruct_robot -> __core__/sound/deconstruct-robot.ogg   (deconstruction planner "eating" sound)

-----------------------------------------------------------------------------
2) BITER / SPITTER / WORM SOUNDS  (data.raw["unit"] and data.raw["turret"])
-----------------------------------------------------------------------------
Biters - small-biter / medium-biter / big-biter / behemoth-biter:
  warcry (plays ONCE when the unit sets out to attack a target - not defined by vanilla, empty by
          default, but a valid override point; fires far less often than attack_parameters.sound
          since it's per-aggro rather than per-swing)
  attack_parameters.sound (roar on EVERY attack swing, cooldown ~35 ticks/0.6s on small-biter -
                            fires very frequently, will blow through any aggregation cap fast)
    small     -> __base__/sound/creatures/biter-roar-1.ogg .. biter-roar-6.ogg
    medium    -> __base__/sound/creatures/biter-roar-mid-1.ogg .. biter-roar-mid-7.ogg
    big       -> __base__/sound/creatures/biter-roar-big-1.ogg .. biter-roar-big-5.ogg
    behemoth  -> __base__/sound/creatures/biter-roar-behemoth-1.ogg .. biter-roar-behemoth-9.ogg
  dying_sound
    small/medium -> __base__/sound/creatures/biter-death-1.ogg .. biter-death-5.ogg
    big/behemoth -> __base__/sound/creatures/biter-death-big-1.ogg .. biter-death-big-5.ogg
  working_sound (idle "calls")
    small     -> __base__/sound/creatures/biter-call-1.ogg .. biter-call-5.ogg
    big       -> __base__/sound/creatures/biter-call-big-1.ogg .. biter-call-big-6.ogg
    behemoth  -> __base__/sound/creatures/biter-call-behemoth-1.ogg .. biter-call-behemoth-6.ogg
  walking_sound
    small/med -> __base__/sound/creatures/biter-walk-1.ogg .. biter-walk-7.ogg
    big/beh   -> __base__/sound/creatures/biter-walk-big-1.ogg .. biter-walk-big-10.ogg

3) PLAYER-BUILT TURRETS  (data.raw["ammo-turret"|"electric-turret"|"fluid-turret"|"artillery-turret"])
-----------------------------------------------------------------------------
gun-turret ("gun-turret", ammo-turret):
  preparing_sound / folding_sound -> sounds.gun_turret_activate / gun_turret_deactivate
                                      __base__/sound/fight/gun-turret-activate-1..4.ogg
                                      __base__/sound/fight/gun-turret-deactivate-1..4.ogg
  open_sound / close_sound        -> sounds.turret_open / turret_close (shared, see below)
  attack_parameters.sound (gunshot) -> sounds.gun_turret_gunshot
                                      __base__/sound/fight/gun-turret-gunshot-1..4.ogg

laser-turret ("laser-turret", electric-turret):
  preparing_sound / folding_sound -> sounds.laser_turret_activate / laser_turret_deactivate
                                      __base__/sound/fight/laser-turret-activate-1..3.ogg
                                      __base__/sound/fight/laser-turret-deactivate-1..4.ogg
  open_sound / close_sound        -> sounds.turret_open / turret_close (shared, see below)
  no distinct firing sound on the turret itself - the beam attack (attack_parameters.type = "beam")
  fires via the "laser-beam" entity, not a turret sound field.

flamethrower-turret ("flamethrower-turret", fluid-turret; defined in prototypes/entity/fire.lua):
  preparing_sound / folding_sound -> sounds.flamethrower_turret_activate / flamethrower_turret_deactivate
                                      __base__/sound/fight/flamethrower-turret-activate-1..4.ogg
                                      __base__/sound/fight/flamethrower-turret-deactivate-1..4.ogg
  open_sound / close_sound        -> sounds.turret_open / turret_close (shared, see below)
  attack_parameters.cyclic_sound (looping fire stream while attacking):
    begin_sound  -> __base__/sound/fight/flamethrower-turret-start-1..3.ogg
    middle_sound -> __base__/sound/fight/flamethrower-turret-mid-1..3.ogg
    end_sound    -> __base__/sound/fight/flamethrower-turret-end-1..3.ogg

artillery-turret ("artillery-turret"):
  open_sound / close_sound -> sounds.artillery_open / artillery_close
                               __base__/sound/artillery-open.ogg / artillery-close.ogg
  rotating_sound.sound         -> __base__/sound/fight/artillery-rotation-loop.ogg
  rotating_sound.stopped_sound -> __base__/sound/fight/artillery-rotation-stop.ogg
  mined_sound -> sounds.deconstruct_large(0.8)
  (firing sound lives on the artillery shell/projectile, not the turret itself)

shared turret open/close sound (all data.raw["...-turret"] types above except artillery):
  sounds.turret_open  -> __base__/sound/open-close/turret-open.ogg
  sounds.turret_close -> __base__/sound/open-close/turret-close.ogg

-----------------------------------------------------------------------------
4) PLAYER / CHARACTER SOUNDS  (data.raw["character"]["character"] and utility-sounds)
-----------------------------------------------------------------------------
character ("character") entity itself only defines one direct sound field:
  heartbeat -> __base__/sound/heartbeat.ogg   (plays at low health)

Everything else player-related lives on utility-sounds (data.raw["utility-sounds"]["default"])
  axe_mining_ore        -> __core__/sound/... (manual mining swing on ore)
  axe_mining_stone      -> __core__/sound/... (manual mining swing on rock/stone)
  mining_wood           -> __core__/sound/... (manual mining swing on trees)
  axe_fighting           -> __core__/sound/... (unarmed/melee punch)
  default_manual_repair  -> __core__/sound/... (repair tool swing, no filename override needed if using default)
  picked_up_item         -> __core__/sound/spawn-item.ogg family (item pickup ding)
  drop_item               -> __core__/sound/... (dropping item on ground)
  inventory_click         -> __core__/sound/... (inventory slot click)
  inventory_move           -> __core__/sound/... (dragging items in inventory)
  clear_cursor             -> __core__/sound/clear-cursor.ogg
  armor_insert / armor_remove -> __core__/sound/armor-insert.ogg / armor-remove.ogg
  switch_gun                -> __core__/sound/switch-gun.ogg
  default_landing_steps     -> __core__/sound/walking/default-land-step.ogg (character footsteps on ramps/platforms)
  build_animated_small/medium/large/huge -> __core__/sound/build-*.ogg (placing buildings by hand)
  deconstruct_small/medium/large/huge -> __core__/sound/deconstruct-*.ogg (deconstruction planner on player-built entities)

NOTE: normal walking footstep sounds (grass/concrete/stone etc.) are NOT on the
character entity - they're defined per-tile in data.raw["tile"][*].walking_sound,
one set per surface material. Ask if you want that full tile-by-tile list too -
it's a much longer table (~30+ tile types x several variations each).
